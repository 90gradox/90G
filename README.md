# 90° / Noventa Gradox

Landing estática de fotografía y producción audiovisual.

## Personalización

- El número de WhatsApp y el ID de YouTube se encuentran en `js/script.js`, en `CONFIG`.
- Reemplaza las imágenes de `images/portfolio/` o modifica el arreglo `projects` en `js/script.js`.
- Las portadas principales están en `images/hero.jpg`, `images/about.jpg` y `images/video-cover.jpg`.

Abre `index.html` en un navegador o publícalo en un hosting estático.
